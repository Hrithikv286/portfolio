ESP32 Environmental Monitoring & Relay Control

DHT11 + LDR · Active-LOW Relay · 2-Second Sensor Loop · Wi-Fi · Firebase

The hardware layer of the Forge Full-Stack Smart Home system is built around an ESP32 development board, which acts as the central controller for environmental monitoring and appliance control. The system integrates a DHT11 temperature and humidity sensor, an LDR for ambient-light measurement, and an active-LOW relay module to create a connected smart-home hardware platform.

The ESP32 continuously monitors the surrounding environment by collecting temperature, humidity, and ambient-light data. The DHT11 provides digital temperature and humidity readings, while the LDR produces an analog signal corresponding to the surrounding light intensity. The ESP32 reads and processes these values at a 2-second interval, allowing the system to continuously track changes in the environment.

For the LDR, the analog readings are processed and smoothed before being transmitted. This helps reduce small fluctuations caused by sensor noise or rapid changes in illumination and provides more stable light-level information for the rest of the system.

The system also includes an active-LOW relay module for controlling an external electrical load. The ESP32 controls the relay through a digital GPIO output, allowing an appliance such as a lamp to be switched ON or OFF. In the active-LOW configuration, the relay is activated when the control signal is LOW and deactivated when the signal is HIGH.

Hardware Architecture

The ESP32 acts as the central interface between the physical hardware and the cloud system. The DHT11 and LDR provide sensor inputs, while the relay provides an electrical output for appliance control. The ESP32 connects to the network through Wi-Fi and communicates the collected information with Firebase, allowing the physical hardware state to be synchronized with the web dashboard.

The overall data flow is:

DHT11 + LDR → ESP32 → Wi-Fi → Firebase → Web Dashboard

For control operations, the flow works in the opposite direction:

Web Dashboard → Firebase → ESP32 → Relay → Electrical Load

This creates a bidirectional connection between the physical environment and the digital interface.

Hardware Demonstration

The hardware prototype demonstrates the complete interaction between the ESP32, environmental sensors, relay module, and connected appliance. The setup includes the sensor connections, GPIO wiring, power connections, relay control circuit, and wireless communication through the ESP32.

The demonstration video shows the practical operation of the hardware, including environmental sensing and relay-based appliance control. The prototype was developed to verify that the individual hardware components could work together reliably as part of the larger Forge smart-home system.
