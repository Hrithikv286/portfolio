1. Project Overview

The MQTT Cloud Dashboard with Relay Control project extends the previous local-network IoT concept into a cloud-connected remote control system.

An ESP32 is connected to the internet and communicates with Adafruit IO using the MQTT publish-subscribe protocol. Commands published through the cloud dashboard are received by the ESP32 through an MQTT subscription, allowing a relay module to control a connected AC load.

Unlike the previous HTTP project, which operated within a local Wi-Fi network, this system enables the device to be monitored and controlled remotely through the internet.

The project demonstrates the integration of embedded systems, cloud IoT, MQTT communication, real-time dashboards and electrical load switching.

2. Project Objective

The primary objective was to develop a cloud-connected IoT system capable of remotely controlling a physical electrical load through an ESP32.

The project focuses on:

  • Understanding MQTT publish-subscribe communication
  • Connecting ESP32 to an IoT cloud platform
  • Implementing remote device control
  • Understanding MQTT topics and feeds
  • Switching an AC load using a relay
  • Monitoring device states through a dashboard
  • Recording control events in the cloud
  • Understanding scalable IoT architecture
  • Applying electrical safety principles when interfacing low-voltage electronics with AC loads

6. MQTT Communication

MQTT stands for Message Queuing Telemetry Transport.

It is a lightweight communication protocol widely used in IoT systems because it is designed for devices with limited processing power, memory and bandwidth.

Instead of directly communicating between the dashboard and ESP32, MQTT uses a central broker.

Publisher

    ▼

MQTT Broker

    │

    ▼

Subscriber

In this project:

  • Adafruit IO acts as the cloud MQTT broker/platform.
  • The dashboard publishes control commands.
  • The ESP32 subscribes to the relevant MQTT feed.
  • The ESP32 receives the command and operates the relay.
  • Device status can be published back to the cloud.

7. Publish-Subscribe Architecture

9. Relay Control

The ESP32 operates at low voltage, while the demonstration load operates from 230V AC.

A relay provides an interface between the low-voltage control electronics and the higher-voltage electrical load.

The ESP32 does not directly supply 230V to the bulb.

Instead, the ESP32 controls the relay's low-voltage input, while the relay contacts switch the AC circuit.

11. Electrical Safety

Because this project involves 230V AC, electrical safety is a critical engineering consideration.

The ESP32 and its low-voltage circuitry must remain electrically separated from the mains side.

Important considerations include:

  • Use a properly rated relay module.
  • Switch the Live conductor rather than relying on switching Neutral alone.
  • Ensure all mains connections are properly insulated.
  • Use a suitable enclosure for exposed electrical connections.
  • Avoid exposed conductors.
  • Use appropriately rated wires, terminals and connectors.
  • Never handle the AC circuit while energized.
  • Disconnect mains power before modifying wiring.
  • Use proper earthing and protection where applicable.
  • For practical deployment, have mains wiring inspected or performed by a qualified electrician.

The 230V section should not be built or modified while energized.

13. Real-Time Operation

The MQTT connection allows commands to be delivered to the ESP32 without continuously requesting the device through HTTP polling.

The basic sequence is:

User changes dashboard control

             ↓

Dashboard publishes MQTT message

             ↓

Adafruit IO receives message

             ↓

MQTT broker forwards message

             ↓

ESP32 receives message

             ↓

ESP32 processes command

             ↓

GPIO state changes

             ↓

Relay switches

             ↓

             ↓

ESP32 can publish updated state

             ↓

Dashboard updates

This creates a near-real-time control loop.

17. Project Outcome

Successfully developed a cloud-connected ESP32 IoT control system capable of receiving MQTT commands through Adafruit IO and controlling a relay-based AC load.

The project demonstrates the complete path from a cloud dashboard command to physical electrical actuation, while introducing MQTT as a scalable communication protocol for connected embedded devices.

The project also provided practical experience in integrating microcontrollers, cloud platforms, wireless communication, MQTT messaging, relay control and electrical safety within a single IoT system.
